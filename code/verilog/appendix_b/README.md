# 附录 B 五个通用模块模板

## 文件

| 文件 | 作用 |
|---|---|
| `fifo.v` | 同步 FIFO，多一位指针判满判空 |
| `cam.v` | 内容寻址存储器，给 key 并行查表，返回命中与位置 |
| `priority_encoder.v` | 优先编码器，从一组请求里找编号最小的置位 |
| `arbiter.v` | 仲裁器，按年龄发最多两张票 |
| `crossbar.v` | 交叉开关，把 N 路输入按目标号路由到 N 路输出 |
| `tb_appendix_b.v` | 自测程序，28 项检查全过 |

## 每个模块在书里的出处

- **fifo** 是第 4 章 FTQ、第 6 章指令缓冲的底座。这里改成参数化深度和位宽，`PTR_W` 用 `$clog2(DEPTH)+1` 自动算，不再写死。
- **cam** 是第 3 章保留站标签匹配、第 10 章发射队列源操作数监听、第 5 章 BTB 查表的共同动作。输入是打包的 `table_i`，用 `+:` 位选切出每一项。多项同时命中时取编号最小项。
- **priority_encoder** 常跟在 CAM 后面，把独热的 match 位编成二进制位置。中断控制器挑最高优先级也是同一个电路。
- **arbiter** 来自第 10 章。两张票分别给年龄最小的两个请求，`limit_i` 控制一拍最多放行几个。
- **crossbar** 是执行结果写回、旁路网络里的选通结构。这里用最简单的"编号小的输入优先"化解输出冲突。

## 三个反复出现的写法

1. **打包向量用 `+:` 位选**。跨越模块边界时，把 N 个表项拼成 `N*W` 位的一个端口，用 `table_i[g*W +: W]` 取第 g 项。比二维数组端口省事，仿真器兼容也好。
2. **打包顺序最右端是 0 号**。`{a3, a2, a1, a0}` 里 `a0` 在最右，占最低位。测试台里写期望值时最容易在这里翻车。
3. **多一位指针判满**。`PTR_W = clog2(DEPTH)+1`，空是两指针相等，满是最高位不同、其余位相同；索引存储器必须取低位 `mem[tail[PTR_W-2:0]]`。

## 两个调试坑

- **`$clog2` 与指针位宽**。深度不是 2 的幂时 `$clog2` 向上取整，判满逻辑按 2 的幂环形队列设计，深度要取 2 的幂才对。这里的模板都假设 `DEPTH`/`N` 是 2 的幂。
- **复位的下降沿和信号建立时间**。测试台里 `rst_n` 从 1 拉到 0 后要在 0 保持几个时间单位再拉高，推数据之后也要留 `#1` 再打时钟，否则第一个时钟沿采不到，症状是第一次 push 没写进去（初版 FIFO 7 项全挂）。
