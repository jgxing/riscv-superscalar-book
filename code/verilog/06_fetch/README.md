# 第 6 章 指令缓冲队列代码

## 文件

- `inst_buffer.v`：指令缓冲队列。每个格子存一个"包裹"，即指令字（32 位）加预译码位（4 位），两者同进同出。
- `tb_inst_buffer.v`：自测程序，24 项检查全过。

## 与第 4 章 FTQ 的区别

| | FTQ（第 4 章） | 指令缓冲队列（本章） |
|---|---|---|
| 存什么 | 取指地址，一个标量 | 指令字 + 预译码位，一组捆绑信号 |
| 生产者 | 分支预测器 | 取指单元 |
| 消费者 | 取指单元 | 译码 / 后端 |
| 骨架 | 都是多一位指针的先进先出队列 | 同左 |

骨架通用，差别在格子里装的东西。指令缓冲里指令字和预译码位必须写同一个格子、读同一个格子；一旦错位，后端会拿着错的分支信息做决定。

## 关键实现点

1. **多一位指针判空满**。深度 8 需 3 位下标，指针留 4 位。`head == tail` 为空；最高位不同、其余位相同为满。判满用**当前 tail**，不能用加一后的值，否则深度会少一格。
2. **索引取低位**。写满时指针会等于 8，用完整指针索引深度 8 的数组会越界。索引用 `head[PTR_W-2:0]` / `tail[PTR_W-2:0]`。
3. **读写同拍**。push 和 pop 两个 `if` 并列写，各推各的指针，互不干扰。
4. **地址上界转 localparam**。iverilog 不接受存储器上界直接写 `[0:DEPTH-1]`，先转成 `localparam DM = DEPTH - 1`。

## 运行

```bash
iverilog -g2012 -o sim.vvp inst_buffer.v tb_inst_buffer.v
vvp sim.vvp
```

应看到 `ALL TESTS PASSED`，错误数为 0。测试覆盖：复位、写满 8 个、满时拒写、逐项配对读出、读写同拍。
